# Network Discovery Detection

- Network discovery: Identifying hosts, ports, services, and other network information.
- Attack surface: The systems and services an attacker could potentially interact with or exploit.
- Attacker objective: Find a viable entry point or identify targets for further attacks.
- Defender objective: Inventory assets, identify unnecessary exposure, and reduce risk.
- Allowlisting: Recognize approved scanning sources, while avoiding overly broad exclusions.
- Threat intelligence: Enrich alerts with information about potentially malicious indicators.
- Behavior-based detection: Identify scanning patterns even when the source is unknown.
- False positive: Legitimate activity incorrectly flagged as suspicious.
- False negative: Malicious activity that detection fails to identify.
