# MITRE

he [MITRE ATT&CK®(opens in new tab)](https://attack.mitre.org/) framework is "a globally-accessible knowledge base of adversary tactics and techniques based on real-world observations. 

- [Tactic(opens in new tab)](https://attack.mitre.org/tactics/enterprise/): An adversary's goal or objective. The “why” of an attack.
- [Technique(opens in new tab)](https://attack.mitre.org/techniques/enterprise/): How an adversary achieves their goal or objective.
- Procedure: The implementation or how the technique is executed.

- **Navigator** → visualizes ATT&CK techniques.
- **ATT&CK** → describes adversary behavior.
- **CAR** → provides detection analytics/research for detecting adversary behavior.

MITRE defines the Cyber Analytics Repository ([CAR(opens in new tab)](https://car.mitre.org/)) as “a knowledge base of analytics developed by MITRE based on the MITRE ATT&CK adversary model. 

**ATT&CK tells you what an attacker does → CAR gives you ideas for how to detect it.**

| Component | Main purpose |
| --- | --- |
| **MITRE ATT&CK** | Describes attacker behavior: techniques, tactics, procedures |
| **MITRE CAR** | Describes analytics that can detect those behaviors |
| **SIEM** | Collects and searches the logs |
| **EDR** | Provides endpoint telemetry and detection |
| **SOC analyst** | Investigates the resulting alerts |

## MITRE D3FEND

With MITRE ATT&CK, you learn how attacks happen, but with MITRE ****D3FEND, you discover how to stop them.
